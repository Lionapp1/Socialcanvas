# SocialCanvas Android
Profesyonel sosyal medya görsel editörü için Android/Compose başlangıç projesi.

## Hazır arayüz
- Instagram 4:5, kare, Story 9:16, Threads/X seçimleri
- Başlık editörü ve karartma kontrolü
- Kişiyi odaklama / metni kişi arkasına alma için UI akışı
- Haber, transfer, skor ve alıntı şablon alanları
- GitHub Actions debug APK build + artifact

## Önemli
Bu paket çalışan editör arayüzü/proje iskeletidir. Kişi segmentasyonu, gerçek katman kompoziti ve bitmap PNG export motoru sonraki production modülleridir; butonlar bu sürümde UI placeholder'dır.

GitHub'a push ettikten sonra Actions > Android APK workflow'u debug APK üretir.
